## Chapter 10 Cheat Sheet — Full Exam Simulation & Strategy

### Pacing Table (2 min/question average)
| Questions Done | Time Elapsed | Status Check |
|---|---|---|
| 30 / 90 | 60 min | On pace if ≥30 done |
| 60 / 90 | 120 min | On pace if ≥60 done |
| 90 / 90 | 180 min | All answered, time left = flag review only |

Behind by 5+ questions at any checkpoint → speed up on recall-style questions, don't rush scenario questions.

### Question Type Triage
| Type | Identify By | Time Budget | Approach |
|---|---|---|---|
| Recall | Asks for a single fact/limit/definition | <1 min | Answer directly from memory |
| Scenario | Multi-paragraph, multiple constraints | 2–4 min | Eliminate infeasible options, then match remaining vs. constraints |
| Cross-domain integration | Combines 2+ domains in one scenario | 3–5 min | Solve each domain's requirement separately, then find the option satisfying both |

### Elimination Strategy
1. Remove technically infeasible options first.
2. Remove options violating an explicit hard requirement (cost cap, compliance rule, SLA).
3. For remaining 2 options, re-read scenario for the ONE differentiating constraint.
4. Never pick based on answer length/technical detail alone — that's a distractor trap.

### Flag-and-Review Workflow
- Never leave a flagged question blank — always lock in a best guess first.
- Flag: (a) questions taking >4 min, (b) genuine 50/50 toss-ups, (c) unfamiliar terminology.
- After finishing all 90, revisit flags lowest-confidence first, using all remaining time.

### Score Interpretation
- Scale: 0–800, passing = 450.
- Scaled score ≠ raw percentage or raw count — it's domain-weighted and difficulty-adjusted.
- A near-miss (e.g., 410) means refine weak domains, not "answer 40 more questions right."

### Final-Week Review Checklist
1. Take one full timed practice exam (180 min, 90 Q) under real conditions.
2. Review every missed and flagged question — understand why each wrong answer was wrong.
3. Re-skim only the heavily-tested concept lists per domain.
4. Do NOT re-read full course notes cover-to-cover — lowest ROI in final week.
5. Re-confirm pacing checkpoints (60/120/180 min) the night before.
