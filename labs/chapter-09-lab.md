# Chapter 9 Lab: AI Security Monitoring, Red-Teaming, and Continuous Evaluation

**Estimated time:** 25 minutes

## Exercise

Build a monitoring and red-team test plan for a production LLM chatbot, listing five detection use cases and three red-team test scenarios mapped to OWASP LLM Top 10 categories.

## Key takeaway

Effective AI security monitoring extends existing SOC capabilities with AI-specific log sources and recurring red-team cycles rather than treating them as one-time or out-of-the-box coverage.
