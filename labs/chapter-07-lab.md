# Chapter 7 Lab: AI Security Architecture and Secure Deployment Patterns

**Estimated time:** 30 minutes

## Exercise

Design a guardrail and isolation architecture (described as a text/pseudo-diagram) for an agentic AI system that can call internal APIs, including trust boundaries and control points.

## Key takeaway

Secure AI architecture depends on layered guardrails, least-privilege tool access, and segmentation across input, retrieval, and output layers — not a single control point.
